# Indievolve 主要产品 · 部署架构

![Indievolve AI 批阅系统部署架构图](assets/deployment.svg)

Indievolve 的主要产品是一套 **AI 批阅系统（PA 系统）**，采用"学校侧边缘设备 + 云端批阅"的两层部署形态。本图最初依据 2026-08-17 周度复盘会议内容整理，已于 2026-08-18 结合 [aireview-grading-system](./codebase-grading-system.md) 与 [aireview-grading-service](./codebase-grading-service.md) 两份代码调研报告核实修正（见文末「与代码事实的核对」）。

## 学校侧（边缘部署）

- **高速扫描仪**：物理扫描 100 份/分钟，是答题卡数据采集的主入口（一体机扫描上限仅 50 份）。
- **批阅一体机**：Win10 触屏终端，集扫描、留痕打印（单次放纸 ≤350 张）、NFC、GPS、4G/Wi-Fi 于一体；可通过触屏适配的 Web 端完成成绩查看、批阅确认等轻操作。
- **设备端软件**：基于厂商/官方 SDK 驱动硬件，负责扫描姿态矫正、PDF 合成、上传，以及 OTA 版本管理（测试版与正式版两套隔离）与设备远程监控。
- **教师终端**：微信小程序（已发版）、iOS/Android（uni-app 一端多出）、Web（三套环境）多端接入。

## 阿里云 · 中心云

> ⚠️ 「双可用区 + ALB/NLB + ECS 弹性伸缩」是 2026-08-17 周会汇报的规划目标；[批阅系统代码调研](./codebase-grading-system.md)核实到的实际部署形态是**单机 Docker Compose**（`update.sh`/`dc.sh` 驱动，多环境 test/demo/prod 同机独立 project），线上 MySQL/Redis 为阿里云**新加坡**区域实例，仓库内未发现对应的多可用区 IaC 证据。下方按「规划态」描述，差异已在本节标注。

- **NLB 负载均衡**（规划：多可用区 + 弹性伸缩；代码实测：单机 Compose，无自动伸缩证据）→ 后端多副本。
- **批阅系统**（学校租户面：建考试 / 批阅 / 讲评）：后端 ×2 负载（代码调研确认此副本数系 2026-08 压测实测选定，非弹性伸缩结果）+ 同步 Worker ×1（从批阅服务回拉结果）。
- **预处理服务**：试卷预处理。
- **批阅服务**（内部，不对外开放）：承载全部批阅逻辑，后端 ×1 + 批阅 Worker ×3；模型调用为**多 provider 路由**而非单一千问调用（见下方「外部依赖」修正）。
- **RDS MySQL / 云 Redis**：代码调研确认位于阿里云**新加坡**实例（非本地直连，需走白名单）；"双可用区 15 天备份"为原周会口径，仓库配置文件未直接证实具体可用区拓扑。

## 外部依赖

- **多模型路由（LLM API）**（修正自"千问 3.7 Plus 大模型"）：[批阅服务代码调研](./codebase-grading-service.md)确认批阅服务实际对接四个 LLM provider——OpenRouter（聚合 Claude/GPT/Gemini，承担主观题提取/评分/验证的默认角色）、Gemini 直连、**通义千问 DashScope**（承担客观题识别的生产配置）、硅基流动。分学科自定义模型 + 评分细则，并支持**学科级思考开关**（如"qwen3.7-plus 语文开、化学关"）。
  - 客观题：千问为主，约 1–2 分钱/份（生产口径）；实测按 qwen3.6-plus 核算约 ¥0.03–0.04/份，量级吻合。
  - 主观题：经 OpenRouter 调用 Claude/GPT/Gemini，单卷成本 $0.47→$0.25（-47%，详见批阅服务报告成本分析）。
- **华为云 OBS**：华汉云历史答题卡原图的迁移源（约 60 万张 / 34 万份，16 并发下载）。

## 关键性能指标（2026-08 压测）

| 环节 | 指标 |
|------|------|
| 高速扫描仪 | 100 份最快 100 秒扫完；矫正 + PDF 合成 38 秒；上传 86 秒；全程 224 秒 |
| AI 批阅 | 100 份并发 ≤90 秒；500 份 ≤17.8 分钟；入库 50–60 份/分钟，峰值 75 份/分钟 |
| 准确率（样本库） | 客观题 100%（903 份答题卡 / 1.6 万题）；主观题 95.4%（5586 题）；作文 89.67% |

## 主链路

答题卡 → 高速扫描仪/一体机 → 设备端软件（矫正 + PDF 合成）→ HTTPS 上传 → NLB → 批阅系统 → 预处理服务 → 批阅服务（Worker 按题型路由多模型：客观题千问 / 主观题经 OpenRouter 调 Claude·GPT·Gemini）→ 结果入 MySQL → 同步 Worker 回拉 → 教师多端确认 / 一体机留痕打印。
